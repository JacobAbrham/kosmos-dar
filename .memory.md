## Architecture Decisions

### LangGraph Agent Framework
- **Decision:** Use LangGraph for all agent implementations
- **Rationale:** Production-proven at Uber/LinkedIn, built-in checkpointing, graph-based workflows
- **Pattern:** All agents extend `LangGraphAgent` base class
- **Location:** `implementation/backend/agents/langgraph_base.py`

### State Management Strategy
- **Decision:** Zustand for global state, Jotai for real-time interdependent state
- **Rationale:** Zustand is simple and accessible outside React, Jotai handles fine-grained reactivity
- **Pattern:** Workspace state in Zustand, agent execution state in Jotai atoms
- **Location:** `implementation/frontend/src/stores/`

### MCP Server Integration
- **Decision:** Use Model Context Protocol for all external tool integrations
- **Rationale:** Standardized by Anthropic/Linux Foundation, adopted by OpenAI/Google/Microsoft
- **Pattern:** Tools discovered dynamically via GlobalToolRegistry
- **Location:** `implementation/backend/core/tool_registry.py`

## Performance Optimizations

### LLM Cost Reduction
- **Pattern:** Use model cascading (Haiku → Sonnet → Opus)
- **Savings:** 60-80% cost reduction
- **Implementation:** `implementation/backend/core/model_router.py`

### Caching Strategy
- **Exact Cache:** Redis with prompt hash keys (30-60% savings)
- **Semantic Cache:** Qdrant vector similarity (15-30% savings)
- **Context Cache:** Anthropic 5-min TTL (50-90% savings)

### Database Queries
- **Pattern:** Always use connection pooling
- **Pattern:** Avoid N+1 queries with eager loading
- **Pattern:** Use pgvector indexes for similarity search

## Known Issues and Workarounds

### Issue: MCP Server Connection Timeouts
- **Symptom:** MCP servers occasionally timeout during tool calls
- **Solution:** Implement circuit breaker pattern with exponential backoff
- **Location:** `implementation/backend/core/circuit_breaker.py`
- **Status:** ✅ Resolved

### Issue: LangGraph Checkpointing Performance
- **Symptom:** Checkpointing slows down agent execution
- **Solution:** Use PostgresSaver with connection pooling, batch checkpoint writes
- **Status:** ✅ Optimized

### Issue: Frontend State Synchronization
- **Symptom:** Zustand state not updating with WebSocket events
- **Solution:** Use Jotai atoms for WebSocket-dependent state
- **Status:** ✅ Resolved

## Tool Integration Learnings

### GitHub MCP Server
- **Best Practice:** Always check rate limits before bulk operations
- **Pattern:** Use GitHub's GraphQL API for complex queries
- **Gotcha:** Personal access tokens expire, use OAuth apps for production

### PostgreSQL MCP Server
- **Best Practice:** Always use parameterized queries
- **Pattern:** Use RLS policies for multi-tenant isolation
- **Gotcha:** Connection pooling is critical for performance

### Qdrant MCP Server
- **Best Practice:** Use payload filtering for multi-tenant queries
- **Pattern:** Create indexes on frequently filtered fields
- **Gotcha:** Vector dimensions must match embedding model

### Model Selection
- **Insight:** 80% of requests can use cheaper models (Haiku/Sonnet)
- **Pattern:** Classify complexity before model selection
- **Savings:** 60-80% cost reduction

### Caching Impact
- **Insight:** Exact cache hits save 100% of LLM costs
- **Pattern:** Cache common queries and classifications
- **Savings:** 30-60% additional cost reduction

### Token Optimization
- **Insight:** Output tokens cost 2-5x more than input tokens
- **Pattern:** Use structured JSON outputs instead of verbose text
- **Pattern:** Use Skills pattern to load only needed tools
- **Savings:** 15-40% token reduction
